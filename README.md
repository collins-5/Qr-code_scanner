# QR Code Scanner

A fast, offline-first QR code scanner for Android. Scan, save, and share QR codes with a clean native experience.

## Features

- **Instant scanning** — point-and-scan with a live tracking frame that follows the detected QR code
- **Scan history** — every scan is saved locally, with favorites and notes
- **Share & save** — export scanned QR codes as real, scannable PNGs, share as text, or copy to clipboard
- **Offline-first** — history and QR generation work without a network connection
- **Torch support** — toggle flash for low-light scanning
- **Light/dark theme** — follows your system appearance

## Download

Grab the latest APK from the [Releases](../../releases) page and install it directly on your Android device.
